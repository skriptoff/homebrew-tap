# achubnet/tap

Homebrew casks for my macOS apps.

```bash
brew tap achubnet/tap
brew trust --cask achubnet/tap/ghbdtn   # Homebrew 7+ asks to trust third-party casks
brew install --cask ghbdtn
```

| Cask | App |
| --- | --- |
| `ghbdtn` | [Ghbdtn](https://github.com/achubnet/Ghbdtn) — fix text typed in the wrong keyboard layout (EN ↔ RU) with ⌥⌘ |
